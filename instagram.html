Follower Instagram

Inserisci un nome utente e scarica l'elenco completo dei follower, pagina dopo pagina, fino all'ultimo.

Prima di iniziare: serve una sorgente dati. Instagram non offre nessun endpoint pubblico che restituisca l'elenco dei follower, quindi questa pagina non può funzionare “da sola”: è il client, la sorgente la scegli tu nel pannello qui sotto.
  • Graph API ufficiale (account Business/Creator collegati a una Pagina Facebook): espone solo followers_count, il numero. La lista dei nomi non è mai stata esposta, e la Basic Display API è stata dismessa a dicembre 2024.
  • Endpoint interno di Instagram (/api/v1/friendships/<id>/followers/): richiede il cookie di sessione, è bloccato dal CORS del browser e il suo uso viola i Termini di servizio.
  • Provider esterni a pagamento (servizi di scraping con API REST): sono l'unica via che funziona davvero da una pagina statica, purché il provider risponda con header CORS. Configura sotto URL, chiave e mappatura dei campi.
  • Un tuo backend / proxy che parla con una delle fonti sopra e ti restituisce il JSON nel formato documentato in fondo alla pagina.
Sorgente dati e mappatura dei campi

Segnaposto disponibili: {username}, {cursor}, {count}. Alla prima chiamata {cursor} è vuoto.

Restano solo nel tuo browser (localStorage): non vengono inviati da nessuna parte se non al provider che indichi tu.

Es. users, data.items. Vuoto = la risposta è già un array.

Quando manca o è vuoto, l'elenco è finito.

Una pausa evita di farsi limitare dal provider.

Stato

Nessun elenco caricato. Scegli una sorgente, scrivi un nome utente e premi Carica follower.

Formato JSON atteso

Con la mappatura predefinita (users / next_max_id) la pagina si aspetta, per ogni chiamata, una risposta di questa forma — e continua a richiedere pagine finché il cursore non sparisce. Se il tuo provider usa nomi diversi, cambiali nel pannello sopra: non serve toccare il codice. 

{
  "users": [
    { "pk": "1234", "username": "mario", "full_name": "Mario Rossi",
      "profile_pic_url": "https://…/foto.jpg", "is_verified": false, "is_private": true }
  ],
  "next_max_id": "QVFE…"   // assente o vuoto sull'ultima pagina
}

L'estrazione massiva di dati da Instagram è vietata dai suoi Termini di servizio e i dati sui follower sono dati personali: usa questo strumento su account tuoi o con il consenso di chi li possiede, e ricordati del GDPR prima di conservare o riutilizzare gli elenchi.
